# Malabar Hub - Restaurant & Hospitality Management System

A fully functional Django web application built for restaurant management, multi-vendor onboarding, table/room bookings, home delivery, and role-based administrative control.

## 🚀 Features
* **User Authentication & Authorization**: Secure login, registration, and logout for customers and partners.
* **Role-Based Access Control (RBAC)**: Distinct permissions for Super Admins, Restaurant Partners, and Customers.
* **CRUD Operations**: Full management capabilities for restaurant profiles, menus, spaces (rooms, tables, banquets), and bookings.
* **Super Admin Dashboard**: Overview metrics, partner verification/approval grid, and restaurant deletion controls.
* **Partner Dashboard**: Custom space, menu, and delivery management for restaurant owners.
* **Responsive UI**: Built using Bootstrap 5 and FontAwesome for seamless mobile and desktop experiences.

## 🛠️ Tech Stack
* **Backend**: Python, Django 6.1
* **Database**: SQLite3
* **Frontend**: HTML5, CSS3, Bootstrap 5, JavaScript
